An interview question on sparse dot products.

dot products

Given two vectors of integers, can you define a data structure to make the dot product between the two efficient (computationally) but with less memory as well?

def store(vec: list[int]) -> list[tuple[int, int]]:
          sparse_vec = []
          for i, elem in enumerate(vec):
              if elem != 0:
                  sparse_vec.append((i, elem))

          return sparse_vec

      def dot(vec1: list[tuple[int, int]], vec2: list[tuple[int, int]]) -> int:
          p1 = 0
          p2 = 0
          dot_prod = 0
          while p1 < len(vec1) and p2 < len(vec2):
              l = vec1[p1][0]
              r = vec2[p2][0]
              if l < r:
                  p1 += 1
              elif l > r:
                  p2 += 1
              else:
                 dot_prod += vec1[p1][1] * vec2[p2][1]
                 p1 += 1
                 p2 += 1

          return dot_prod

      v1 = [1, 0, 0, 8, 1]
      v2 = [0, 1, 2, 5, 2]
      vec1 = store(v1)
      vec2 = store(v2)
      dot(vec1, vec2)

complexity

If our vectors have $n_i$ elements with $k_i$ non-zero elements for $i\in\{1,2\}$, then this runs in $k_1+k_2\ll n_1+n_2$ if the vectors are sparse. However... this store phase still requires $n_1+n_2$ passes, so I am not sure if this is really useful unless we always add elements in the new structure to begin with.
