Site setup guide

A minimal static site: plain HTML, one CSS file, zero build steps, zero npm. Runs anywhere that serves files — GitHub Pages, Netlify, a VPS, even python -m http.server.

1. Folder structure

site/
      ├── index.html              ← homepage
      ├── assets/
      │   ├── css/main.css        ← all styles (edit this to change look)
      │   └── js/main.js          ← nav active-state + iframe helper
      ├── notebooks/
      │   ├── index.html          ← experiment listing
      │   ├── Optimization2.html   ← wrapper page for a notebook
      │   └── Optimization2_raw.html  ← nbconvert output (you generate this)
      ├── thoughts/
      │   ├── index.html          ← thought listing
      │   └── example.html        ← template for a post (copy this)
      ├── quotes/
      │   └── index.html          ← quotes masonry grid
      └── books/
          └── index.html          ← book table with category filter

2. Local preview

No build step needed. From the site/ directory:

python -m http.server 8000
      # open http://localhost:8000

Or with Node (if you have it):

npx serve .

Do not open HTML files directly in the browser via file:// — relative paths for the iframe and assets will break. Always use a local server.

3. Adding a notebook

Step 1 — convert

pip install nbconvert

      # Basic HTML (lightweight, just the outputs)
      jupyter nbconvert --to html your_notebook.ipynb

      # Lab-style (nicer code highlighting, heavier file)
      jupyter nbconvert --to html --template lab your_notebook.ipynb

This creates your_notebook.html alongside the .ipynb file.

Step 2 — copy files

cp your_notebook.html site/notebooks/your_notebook_raw.html

Step 3 — create a wrapper page

Copy notebooks/Optimization2.html → notebooks/your_notebook.html. Edit the three things at the top:

<title>Your Title · experiments · notebook</title>
      ...
      <h1>Your Title</h1>
      <p class="meta">2026-01-15 · topic · topic</p>
      ...
      <iframe src="your_notebook_raw.html" ...>

And update the "open full page" link:

<a class="btn" href="your_notebook_raw.html" target="_blank">open full page ↗</a>

Step 4 — add to the listing

In notebooks/index.html, add a list item inside <ul class="entry-list">:

<li>
        <a href="your_notebook.html" class="entry-link">
          <span class="entry-title">Your notebook title</span>
          <span class="entry-tag">notebook</span>
          <span class="entry-date">2026-01-15</span>
        </a>
      </li>

Do the same in index.html under "Recent experiments".

Alternative: inline instead of iframe

If you prefer the notebook to render inline (no scroll-within-scroll):

  1. Run jupyter nbconvert --to html --template lab your_notebook.ipynb
  2. Open the output HTML, select everything between <body> and </body>, copy it.
  3. In the wrapper page, delete the <iframe> block and paste the copied HTML

inside <div class="notebook-inline">.

  1. Add this CSS to the wrapper's <style> block to strip the notebook's own background:
   .notebook-inline { background: transparent !important; }
         .notebook-inline .jp-Notebook { background: transparent !important; padding: 0; }

Optional: live execution via Binder

If your repo is on GitHub, you can offer a live-run button for free:

<a class="btn"
         href="https://mybinder.org/v2/gh/YOURUSER/YOURREPO/HEAD?filepath=your_notebook.ipynb"
         target="_blank">run on binder ↗</a>

Replace YOURUSER and YOURREPO. Binder builds a Docker image from your repo's requirements.txt or environment.yml. First launch is slow (~2 min); subsequent ones use a cached image.
